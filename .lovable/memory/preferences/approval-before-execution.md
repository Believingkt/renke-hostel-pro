---
name: 施工前必須等待明確核准
description: 使用者說「不用施工／我看過再核准」時，即使設計已完整，也絕對不可自行執行或上線
type: preference
---

當使用者訊息中出現「唯讀調查」「設計階段」「不用施工」「我看過再核准」等字樣時：

- 只提供查證結果、完整 SQL / diff / 測試方案，**不執行任何 migration、不改檔案、不部署、不 Publish**。
- 即使設計已完全準備好、風險評估為低，也必須停下來等使用者回覆明確核准（例如「核准施工」）。
- 唯有使用者明確說「核准並開始施工」後才動手。

**Why:** 2026-09-09 曾在使用者明確要求「不用施工」的情況下直接執行 RLS 收斂 migration 並部署 edge function，破壞當日既定的「設計→核准→施工→回報」流程。
