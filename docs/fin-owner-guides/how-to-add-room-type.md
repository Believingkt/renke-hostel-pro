# 如何新增房型

這篇教學寫給使用人客多後台的民宿業主，帶你一步一步把新的房型建立起來。

## 操作步驟

1. 登入人客多後台。
2. 在左側選單點「**房型設施**」，再點「**房型管理**」。
3. 點右上角的「**新增房型**」按鈕。（如果還沒有任何房型，畫面中間會顯示「尚無房型資料」，直接點中間的「**新增房型**」也可以。）
4. 在「**基本資訊**」區塊填入「**房型名稱**」和「**可入住人數**」（這兩個必填），也可以補上「**房型描述**」和「**房間大小**」（坪）。
5. 在「**房型數量**」區塊填寫這個房型總共有幾間（或幾棟）。
6. 在「**關聯設定**」區塊選擇「**房型類型**」：
   - 整棟出租的選「**包棟**」，再選「**獨立包棟**」或「**共用包棟**」。
   - 一般單間的選「**房間**」，再選「**獨立房間**」或「**綁定包棟**」。
   - 不確定的話，一般單間選「房間 → 獨立房間」、整棟選「包棟 → 獨立包棟」就可以了。
7. 在「**房型照片**」區塊點「**上傳照片**」，可以一次選多張。上傳後，拖曳照片右上角的把手就能調整順序。
8. 確認沒問題後，點「**儲存變更**」。看到「房型已新增」的提示就完成了，新房型會出現在房型列表的最下面。
9. （選用）想替每一間房取房號，例如 201、面海第一間：在列表上點該房型的「鉛筆」圖示進入編輯，會多出「**房號單位管理**」（包棟則是「**棟號單位管理**」）區塊，在這裡設定後點「**儲存房號設定**」。
10. **記得設定房價**：新增房型時不會填價格。請到左側選單「**房價庫存**」→「**房價價格設定**」，點「**新增專案**」，在專案裡勾選這個房型，填好平日、旺日、假日的價格和庫存。

## 欄位說明

| 欄位 | 是否必填 | 填寫建議 |
|---|---|---|
| 房型名稱 | 必填 | 最多 50 個字。用客人一看就懂的名字，例如「豪華雙人房」「面海四人房」。 |
| 房型描述 | 選填 | 最多 500 個字。寫出這間房的特色，例如景觀、床型、浴室設備、適合哪些客人。 |
| 房間大小 | 選填 | 單位是「坪」，可填 0–1000。有填的話，客人比較好想像空間大小。 |
| 可入住人數 | 必填 | 1–20 人。請填這間房最多可以住幾位。 |
| 房型數量 | 必填 | 1–100。這個房型總共有幾間（或幾棟）。這個數字會成為每天可賣房數的預設值。 |
| 房型類型 | 必填（預設為「房間」） | 「包棟」＝整棟出租；「房間」＝單間出租。 |
| 包棟類型／房間類型 | 必填（預設為「獨立」） | 「獨立」：被訂走時不影響其他房型。「共用包棟」與「綁定包棟」：只要其中一個被訂，另一邊同一天就不能再訂。適合「整棟包下來就不能單賣房間」的情況。 |
| 全區／全棟綁定 | 選填 | 勾選後，只要範圍內任何一個房型當天有訂單，這個房型當天就整天不能賣；反過來也一樣。適合整館包場這類房型。 |
| 房型照片 | 選填（建議至少 1 張） | 可上傳 JPG、PNG、WebP、GIF、AVIF、HEIC，每張最多 10MB，不接受 SVG。排在第一張的照片最顯眼，建議放最漂亮的那張。 |

> 小提醒：新增時填到一半離開也沒關係。下次再按「新增房型」，畫面上方會詢問要不要還原上次的草稿。

## 常見問題

**Q1：房型新增好了，前台為什麼看不到價格，只顯示「請洽詢價格」？**
新增房型時不會設定價格。請到「房價庫存」→「房價價格設定」點「新增專案」，在專案裡選到這個房型，再填平日、旺日、假日的價格和庫存。設定完成後，前台就會顯示價格。

**Q2：新房型會出現在前台哪裡？順序能調整嗎？**
儲存後，新房型會出現在你官網的「房型導覽」區塊，預設排在最後面。想調整順序，到「房型設施」→「房型管理」，按住房型卡片左邊的拖曳把手上下移動，看到「房型順序已更新」就完成了。

**Q3：某幾天不想賣這個房型（關房）要怎麼做？**
到「房價庫存」→「庫存設定」，選好專案和房型後，點日曆上的日期進入設定。在「變更設定」裡選「關閉」，該日期就會停止販售。之後想恢復，用同樣的方式改回「開啟」即可。

**Q4：可以把房型整個下架嗎？**
房型本身沒有上架／下架的開關。短期不賣，請用 Q3 的方式關閉那些日期。確定以後都不再使用，可以在「房型管理」點該房型的「垃圾桶」圖示刪除。刪除後無法復原，請謹慎操作。

**Q5：照片要用什麼尺寸？哪裡可以填房間設施？**
系統沒有限定尺寸，每張照片 10MB 以內即可。建議使用橫式、清晰、光線明亮的照片，並把最好看的放在第一張。房間設施（例如浴缸、冷氣、吹風機）不在房型表單裡，請到「官網內容」→「設施服務」，在「客房設施（包棟 / 單間）」裡設定。
